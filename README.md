# 🏥 CareHub – Healthcare Appointment Management System

CareHub is a web-based healthcare appointment management system built using HTML, CSS, and JavaScript. It helps patients explore available doctors, check their schedules, submit health concerns, and book appointments. Administrators can manage doctor availability, appointments, and alternative doctor selection when a preferred doctor is unavailable.

## ✨ Features

- 👨‍⚕️ **Doctor Directory** – Browse doctors and their details.
- 📅 **Doctor Availability** – View available dates and schedules.
- 🩺 **Health Concern Submission** – Enter the reason for requesting an appointment.
- 📋 **Appointment Booking** – Select a doctor and suitable appointment date.
- 🔄 **Alternative Doctor Selection** – Choose another available doctor when the preferred doctor is unavailable.
- 🛠️ **Admin Dashboard** – Manage doctor details, schedules, and appointments.
- 📊 **Appointment Status Tracking** – Monitor appointment progress.

## 🛠️ Technologies Used

- **HTML5** – Structures the web pages.
- **CSS3** – Styles the interface and provides responsive layouts.
- **JavaScript** – Handles user interactions, appointment workflows, and dynamic content.

## 🚀 Getting Started

### Prerequisites

- A modern web browser such as Chrome, Firefox, or Edge.
- A code editor such as Visual Studio Code (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd CareHub
   ```

3. Open `index.html` in your browser to run the application.

   Alternatively, use the **Live Server** extension in Visual Studio Code for local development.

## 🔄 How It Works

1. Patients browse the available doctors.
2. They check doctor schedules and availability.
3. Patients provide their health concerns and select a suitable appointment.
4. If the selected doctor is unavailable, another available doctor can be chosen.
5. The admin manages doctor information, schedules, and appointment requests.
6. Appointment statuses can be monitored through the interface.

## 🎯 Project Objective

CareHub aims to simplify doctor discovery and appointment coordination by providing a centralized interface for patients and administrators, improving schedule visibility and helping patients find suitable available doctors.
