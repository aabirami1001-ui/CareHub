CAREHUB SOURCE CODE — SPLIT VERSION

Files:
1. index.html — page structure and interface sections
2. style.css — page design, layout, colors, and responsive styling
3. app.js — login flow, role navigation, patient/doctor records, appointments, diagnosis suggestions, prescriptions, billing, analytics, and browser localStorage data handling

How to run:
1. Extract this ZIP into a folder.
2. Keep index.html, style.css, and app.js in the same folder.
3. Open index.html in a modern browser.

Important implementation note:
This source currently stores its demo data in browser localStorage. It is not yet connected to a PHP/MySQL server database, and its role/login checks should not be treated as production-grade security. Diagnosis suggestions are rule-based demo suggestions and are not a substitute for a qualified clinician's diagnosis.
